# CampusHelp – University Student Service Request Portal

**Project Management Assignment – GitHub-Based Project (Team 01)**
Project Manager / Analyst / QA: **Munir Xammrayev** (individual submission – all three roles held by one member)

CampusHelp is a proposed web portal where students submit IT, classroom-maintenance, library and administrative requests, track them by a unique request ID, and where administrators assign and update requests from a dashboard.

This repository holds the project management documents, the wireframes, a clickable prototype and the evidence of the work.

> **Mock exercise:** the project follows a simulated 10-day schedule (Day 1 = Wed 11 Nov 2026, Day 10 = Tue 24 Nov 2026). Documents report the simulated status on those days; GitHub timestamps show when the repository was actually built.

## Running the prototype

Open `prototype/index.html` in any browser. No server or installation is needed.
Data is held in memory only; email, login and database storage are **simulated** (outside the project scope).
