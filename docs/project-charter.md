# Project Charter – CampusHelp

| Charter component | Information |
|---|---|
| **Project title** | CampusHelp – University Student Service Request Portal |
| **Business problem** | Student service requests (IT support, classroom maintenance, library assistance, administrative services) arrive by email and paper forms. Requests get lost, nobody can see their status, and the university cannot measure response times. |
| **Project objective** | Plan and demonstrate a centralized web-based request management portal through project documentation, interface mockups and a clickable prototype, within 10 working days. |
| **Project sponsor** | University Administration (simulated) |
| **Project manager** | Munir Xammrayev (Role A) |
| **Stakeholders** | Students, IT support staff, administrators, maintenance staff, library staff, lecturer (assessor) |
| **Project duration** | 10 working days – Wed 11 Nov 2026 to Tue 24 Nov 2026 |
| **Project budget** | 45 planned person-hours × 50,000 UZS = **2,250,000 UZS** (simulated). Management reserve: 10% (225,000 UZS / 4.5 h) |
| **In scope** | Request submission, categories and priority, unique request ID tracking, admin assignment, status updates, dashboard (open / ongoing / completed) – as requirements, wireframes and a clickable prototype |
| **Out of scope** | Real authentication, production server or hosting, real database, live SMS/email services, integration with university systems, mobile app |
| **Constraints** | One team member covering three roles; 10 working days; 45 planned hours; no paid external services; GitHub Free only |
| **Assumptions** | The prototype may simulate data in memory; the lecturer accepts a single-member submission; GitHub remains available; a working day ≈ 4–5 hours of project effort |

## Measurable objectives

1. All six proposed system features are covered by requirements and by the prototype.
2. All four milestones are created in GitHub with calendar due dates and completed by Day 10.
3. All 12 mandatory Issues are created with the full description format, assigned and linked to a milestone.
